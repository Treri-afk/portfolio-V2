# 0006 — Lint, tests et CI

- Statut : accepté (17/10/2026)
- **ESLint 10** (`eslint.config.mjs`) : typescript-eslint strict type-checked, React (`@eslint-react`, `react-hooks` avec les règles du React Compiler), accessibilité (`jsx-a11y-x`), frontières Feature-Sliced Design (`boundaries/dependencies`), cycles (`import-x/no-cycle`). Règles propres au projet : couleurs et unités CSS interdites dans le code, `style` limité aux custom properties, pas d'`enum`, pas d'assertion `as`, pas de `useEffect` / `useMemo` / `useCallback`, imports via `index.ts`, nombres magiques, 25 lignes par fichier et 20 par fonction (exceptions de l'ADR 0005).
- **Stylelint** (`stylelint.config.mjs`) : toute propriété de design doit lire un token (`declaration-strict-value`), hex, fonctions de couleur, unités et media queries brutes interdits. L'inclinaison est réservée à `Slice`, `SlantRule` et `app/styles/view-transitions.css` (`declaration-property-value-disallowed-list` sur `clip-path: polygon`, `rotate`, `transform: skew/rotate/scale`).
- **Vitest** : tokens (angles dans [2°, 20°] hors multiples de 45°, contraste AA de chaque paire texte/surface dans les deux thèmes, tokens sémantiques et composants uniquement en alias), contrats Zod, logique pure, validation de tout le contenu Markdown, deux composants (jsdom).
- **CI** (`.github/workflows/ci.yml`) : trois jobs parallèles (lint + typecheck, tests, build), token en lecture seule, actions épinglées par SHA, Node depuis `.nvmrc`, `npm ci` sans scripts d'installation.
- **Chaîne d'approvisionnement** : outils installés avec `npm install --before` pour n'accepter que des versions publiées depuis au moins une semaine (npm n'a pas encore de `min-release-age`).
- **Audit des dépendances de dev** : `handlebars` (via `eslint-plugin-boundaries`, version figée vulnérable) est forcé en 4.7.10 par `overrides`. `braces` 3.0.3 (via `micromatch`) reste signalé sans version corrigée publiée : la faille est un déni de service sur des motifs glob, que seuls notre configuration et nos fichiers fournissent ; aucun code de production n'en dépend. À retirer dès qu'un correctif sort.
- Preuve : un fichier volontairement fautif (TSX et CSS) déclenche les 10 règles ESLint et les 14 erreurs Stylelint attendues ; il a été supprimé.
- À venir : Playwright + axe, Lighthouse CI, knip, jscpd, hooks Git (lefthook), protection de `main` avec ces checks requis.
